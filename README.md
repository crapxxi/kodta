## 👨‍💻 Обо мне

Я — разработчик программного обеспечения, специализирующийся на backend-архитектуре, высоконагруженных системах и низкоуровневом программировании. 

На сайте **kodta.me** я делюсь опытом разработки:
*   **Системное программирование:** Создание кастомных in-memory баз данных (C++), аллокаторов памяти и многопоточных серверов.
*   **Backend & Микросервисы:** Проектирование REST API, работа с базами данных (PostgreSQL, Redis) и контейнеризация (Docker, Nginx) с использованием Java и Go.
*   **Machine Learning / NLP:** Разработка архитектур нейронных сетей и инструментов обработки естественного языка (PyTorch, C++).
